# Licenses

See [dependency inventory](LICENSE-INVENTORY.md) and [source-separation review](SOURCE-SEPARATION.md).

- V3 uses FFmpeg externally plus permissive Python libraries; inspect the deployed FFmpeg build before commercial release.
- Demucs code is MIT, but pretrained weight rights are unclear for commercial reliance. It is excluded from the active V3 image.
- Pedalboard and Matchering are excluded because GPL-3 conflicts with the intended proprietary distribution strategy.
- Open-Unmix default `umxl` weights are noncommercial and excluded.
- No separation model activates until code and weight licenses are approved.

This is engineering documentation, not legal advice. Commercial launch requires final review.
